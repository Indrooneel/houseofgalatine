01 / The gap

The last unguarded boundary

Security watches what happens.
MIG controls whether it happens.

01

Protocols trust the network.

Industrial protocols like Modbus TCP were designed for availability, not adversarial environments. If a command reaches the controller, it is usually accepted.

No identity
02

Controllers trust the command.

A PLC cannot tell an operator from an attacker — or a capable AI agent from a confused one. It executes the instruction it receives.

No intent
03

Detection arrives after execution.

Alerts are essential, but they do not close the valve or reject the unsafe setpoint. For high-consequence actions, observation alone is too late.

No veto
!

The common failure mode: a system received a syntactically valid command that should never have been allowed to execute. MIG creates the missing veto point.

Three possible outcomes

A decision — not another alert.

01

Allow

Within policy and acceptable risk. Forward the command and record the trace.

02

Approval

Legitimate but sensitive. Hold execution until the right human explicitly confirms.

03

Deny

Outside policy or above risk tolerance. The protected system never sees the command.

Fail-closed rule

No policy match → deny   /   MIG unreachable → deny   /   Pipeline error → deny
