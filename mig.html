01 / The control gap

Access is not authorization

A tool grant says what an agent can reach.
MIG decides whether this action may run now.

01

Identity needs context.

A credential identifies the requester. It does not establish whether this operation, payload, destination, and moment are within policy.

Identity
02

Tool access is broad.

One tool can expose routine reads, sensitive exports, destructive writes, and external destinations with very different consequences.

Intent
03

Logs arrive after the fact.

Telemetry supports investigation. Consequential actions also need an authorization decision before the protected system accepts them.
